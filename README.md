# StudySync

An academic dashboard web app for Tshwane University of Technology (TUT) students. StudySync helps students track assessments, build study streaks, and work through structured learning paths.

## Features

- **Assessment Tracker** – log and monitor upcoming and completed assessments
- **Study Streaks** – daily streaks logged automatically when you complete learning activities
- **Learning Nodes** – structured, node-based learning paths with progress tracking
- **Predicate Calculator** – a logic tool for working through predicate expressions
- **AI Quiz Gate** *(in progress)* – AI-generated quizzes that gate progression between nodes
